# Kaggle Learner

<!-- Where: .agents/skills/kaggle-learner. What: 過去解法の学習。 Why: 検証済みの着想を新しい実験に転用する。 -->

1. 大会、分野、知りたい手法を確認し、上流の知識ベースから対応する大会別ノートを読む。見つからなければ、過去大会の公開解法記事を元に調べる。
2. 順位・評価指標、データ分割、モデル、特徴量、後処理を整理する。数値や改善効果は、解法記事や公開コードで確認できた範囲を明示し、出典を添える。
3. 転用候補ごとに必要なデータ、計算量、リークの可能性、現在のCVで確かめる最小実験を示す。
4. 参加中コンペの投稿やコメントを収集する依頼は `$kaggle-discussion-research`、Notebookのfork系譜や実装を比較する依頼は `$kaggle-notebook-research` を使う。
